Brand guidelines — v1
Djaunt

One identity across music, software, and art. Gold dragon on warm near-black, bone as the second voice, and eight elemental variants for when a project needs a different mood. Everything here is enforced by tokens.css and described for agents in BRANDING.md.

01 — The mark

Three assets, one dragon

Djaunt lockup
djaunt-lockup.svg
Default. Min width 120px.
Djaunt icon
djaunt-icon.svg
Stands alone. Favicons, app icons, avatars. Min 16px.
Djaunt wordmark
djaunt-wordmark.svg
Text-led contexts. Min width 80px.
Do
  • One flat color: gold or bone on dark, ink on light or gold.
  • Clear space of at least one wordmark D-height on every side.
  • Prefer the currentColor files so themes recolor the mark for free.
  • Crop and scale the dragon as a background graphic at 4–10% opacity.
Don't
  • Gradients, glows, or shadows on the mark itself.
  • Rotate, stretch, redraw, or re-proportion the dragon.
  • Badge it in a circle or rounded square, outside platform app icons.
  • Place it over busy imagery without a solid plate behind it.
02 — Core color

Gold, bone, ink

Gold is a highlight, never a surface. Bone carries every word of body text — pure white is off-brand. Ink is warm-biased near-black, not neutral grey.

03 — Elemental dragons

Nine themes, one system

Each theme swaps the accent and the background family. Type, spacing, geometry, and the semantic colors never move. One theme per surface — an element is a mood for a whole product, not a palette to pick from per component. The demo card below defaults to and follows the picker above; its own hoard/fire/frost/… buttons let you preview any theme locally without moving the rest of the page.

04 — Typography

Archivo, Plex Sans, Plex Mono

Display — Archivo 700 tracking -0.02em · line-height 1.08
Here be dragons
Body — IBM Plex Sans 400 line-height 1.6 · max 72ch

Djaunt covers music, software, and art without splitting into separate identities. The dragon and the gold do the distinguishing work, so the writing can stay plain: say what the thing is, say what it does, and stop. Body copy never runs in the display face, and long text never runs in mono.

06 — Terminal & code

Djaunt Hoard, in nine elements

A 16-color ANSI scheme and a matching syntax theme, so a Djaunt tool still looks like Djaunt inside a shell or an editor — every slot below is derived from the active element's own tokens, not hand-picked per theme, so it follows the picker above like everything else.

// theme is a mood, not a palette
export function applyTheme(el, name = 'hoard') {
  el.setAttribute('data-dj-theme', name);
  return THEMES[name] ?? THEMES.hoard;
}
07 — For agents

Point a tool at this repo

Full instructions live in BRANDING.md. This is the short version.

<link rel="stylesheet" href="brand/tokens/tokens.css"> <link rel="icon" href="brand/favicon/favicon.svg"> <html data-dj-theme="hoard">
  1. Import tokens.css; consume role variables only, never a raw hex.
  2. Load Archivo, IBM Plex Sans, IBM Plex Mono. No fourth family.
  3. Default to dark and hoard unless the brief names an element.
  4. Copy the logo files you need out of brand/logo/ — prefer the currentColor variants.
  5. Shallow radii, hairline borders, one glow, stroke icons, no emoji.
  6. Need several simultaneous meaningful colors on one surface (categories, lanes, a gauge)? Use --dj-accent-2/3/4 before inventing anything project-specific.
  7. If a decision isn't covered, choose the more restrained option.
